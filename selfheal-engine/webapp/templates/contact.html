Frequently Asked Questions
How does SelfHeal avoid masking real bugs?
Deterministic triage executes before any LLM is called. If HTTP ≥ 500 or error alerts occur, triage immediately tags APP_BUG and halts with FAIL_FUNCTIONAL, refusing to engage the healing agent.
Does the agent have access to live credentials?
No. Recipe steps reference field_key identifiers only. Raw values are injected strictly by deterministic test runners from the immutable intent test data.
What happens if Gemini API hits daily rate limits?
Per Rule 12, the system never fakes AI. When quota 429 occurs, it falls back to a verified golden trace, transparently labeled RECORDED, which still undergoes full validator and clean replay checks.
How is MongoDB used in this project?
MongoDB permanently archives all test runs, execution timelines, AOM diffs, triage decisions, contact submissions, and versioned recipes (v1, v2) with cryptographic intent hashes.
