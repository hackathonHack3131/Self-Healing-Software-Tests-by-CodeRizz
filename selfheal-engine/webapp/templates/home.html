PARADIGM SHIFT

The Problem vs. The SelfHeal Solution

Why modern engineering teams waste hours fixing brittle test suites, and how intent-aware testing eliminates maintenance toil.

Traditional Brittle Tests

Fragile Selectors & Fixed Paths

  • Rigid Locators: Bound to brittle selectors like click("#checkout-btn") or fragile XPath.
  • Breaks on Harmless Redesign: Converting a single form into a multi-step wizard breaks the entire test suite.
  • Endless Engineering Maintenance: Teams spend hours repairing locator syntax instead of verifying business functionality.
  • Flaky & Opaque: Fails with generic ElementNotFoundException without root cause triage.
SelfHeal Intent Architecture

Immutable Goals & Adaptive Workflows

  • Immutable Intent Contract: Test specifies business goal ("Complete checkout with a valid credit card") and invariants.
  • Autonomous Workflow Reconstruction: Detects UI drift, discovers new wizard pages, and reconstructs the full multi-step path.
  • Strict Defect Classification: Rule engine identifies genuine bugs (HTTP 500, math errors) and refuses to falsely heal them.
  • Clean Replay Verification: Re-executes the rebuilt recipe from scratch in an isolated browser session. The AI never decides pass/fail.

ENGINEERING INTEGRITY

Core System Principles

Built with strict constraints to ensure automated testing is safe, predictable, and enterprise-ready.

Immutable Intent

The goal and invariants are cryptographically hashed. The agent can never modify test criteria or expectations to force a pass.

Deterministic Verifier

AI models propose actions, but only deterministic code decides pass or fail during a from-scratch replay in a fresh browser session.

No Generated Scripts

No LLM-generated Python, JavaScript, shell, eval, or exec. The model proposes strictly typed semantic actions validated before execution.

Local MongoDB Persistence

Every execution, UI diff, triage diagnosis, and versioned recipe (v1 → v2) is logged with complete cryptographic lineage.

Origin Allowlist Guard

Strict network routing ensures the browser automation visits only registered, allowlisted target endpoints (:5000).

AOM Accessibility Snapshots

Structural comparisons rely on accessible names, roles, and headings. Sensitive passwords and credit card inputs are never stored.
